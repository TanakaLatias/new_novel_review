### 物語をより深く楽しむためのサービス - NovelReview -
###### 作成経緯  
好きな物語（小説/漫画/映画/ドラマなど）について、どこがどう好きだと思ったのか投稿することで、物語をより深く楽しむためのサービスを作ろうとした。  
###### 言語  
Django
###### 機能  
・Email認証つき会員登録  
・好きな物語に関する投稿作成  
・投稿に対するいいね  
・物語の好きなシーン投稿作成  
・物語の好きなシーン投稿に対する投票（＝いいね）
